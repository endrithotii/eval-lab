Why hallucination is counted on its own

A model that misreads a number and a model that invents one are different risks. A value counts as stated only if it appears in the text the model saw; otherwise the right answer is null, and any value is counted as invented.

The hallucination rate is the invented answers divided by the fields whose right answer is null.

Answer key: ClinicalTrials.gov structured fields. Every answer, score, latency and token count is stored in runs.db.
